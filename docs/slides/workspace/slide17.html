Getting Started

Quick Start

1

Install dependencies

pip install -e ".[dev]"

2

Run unit tests (no GCP credentials needed)

python -m pytest tests/test_agent.py tests/test_mcp_agent.py tests/test_a2a_agent.py -v

3

Provision Discovery Engine and data stores

bash infra/provision_engine.sh && bash infra/provision_datastore.sh

4

Deploy agents to Agent Engine

cd src && adk deploy agent_engine --project=YOUR_PROJECT agent

5

Launch frontend

python -m src.frontend # http://localhost:8080
